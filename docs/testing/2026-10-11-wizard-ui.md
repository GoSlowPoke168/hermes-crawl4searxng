# Native wizard presentation verification

The setup wizard now uses Hermes's public `curses_radiolist` helper, the same
component used by Hermes setup. Choices and yes/no prompts have dot selectors,
arrow navigation, Enter selection, and Escape/Ctrl+C cancellation. Hermes owns
the numbered fallback for terminals without curses. Its helper signature was
checked in the declared minimum v0.21.6 source.

The four sections are extraction, search, optional research features, and review.
A Rich text panel displays the endpoint/routing/deployment summary with hidden
token status; the same summary is passed into the confirmation selector so it
survives the curses screen clear. Confirmation still defaults to No. User values
are rendered as plain Text rather than Rich markup. No dependency was added.

## Observed checks

- New selector/default/description expectations failed against the old wizard.
- `hermes --run-module unittest discover -s tests -v`: **27 tests passed**.
  Existing six service-path and persistence/failure checks use the real native
  numbered fallback with a forced unavailable curses screen. Added checks cover
  native selector defaults, cancellation before mutation, and review context.
- Real PTY runs invoked the native CLI in disposable profiles pointing at the
  current source, using the installed Hermes bootstrap. Dot characters and
  actual arrow-key movement were observed for existing/existing and managed/keep
  current previews. Enter on default No cancelled without configuration or
  credential writes. A controlled fake token was not echoed.
- Separate Escape and Ctrl+C terminal runs cancelled before any mutation.
- Fresh read-only code review: no findings; helper compatibility at v0.21.6 confirmed.
- `git diff --check`: passed.

Terminal harness and logs are retained under ignored
`.implementation/.test-artifacts/check_wizard_terminal.py`, `wizard-ui-terminal.log`,
and `wizard-ui-{escape,existing,managed,interrupt}/terminal.log`.

These terminal previews cancel before deployment and do not upgrade the README's
experimental deployment support status. Existing live deployment evidence is in
`2026-10-10-verification.md`; container images and deployment code did not change.
Other operating systems and terminal emulators have not been tested.
